# AlopetsiyaSkins

Клиентский NeoForge-мод для сервера АлопецияКрафт: рисует игроков в скинах,
загруженных на сайт, — вместо Стива, которого показывает offline-режим.

## Что делает мод

- Скачивает полный PNG скина с сайта по нику игрока
  (в offline-режиме ник в игре = ник сайта)
- Подменяет скин миксином в `PlayerInfo.getSkin()` — этим одним вызовом
  покрыто всё: модель игрока, портреты в табе (Tab), рука от первого лица
- PNG 64×128 даёт модель Alex (slim), 64×64 — широкую
- Всё кешируется по сессии; неудачные попытки повторяются не чаще раза в минуту
- Если у игрока нет скина на сайте или сайт недоступен — остаётся Стив

Мод чисто клиентский: миксин лежит в секции `"client"` файла
`alopetsiyaskins.mixins.json` и на выделенном сервере не применяется.
Серверу мод не нужен — это дополнение только для глаз игрока.

### Почему не серверный мод (SkinRestorer и т.п.)

С версии ~1.20.2 ванильный клиент показывает чужие скины только если
текстуры подписаны ключом Mojang, а подписать может только Mojang. Поэтому
серверный подменщик работает лишь для самого игрока (остальные видят Стива),
а клиентский мод подменяет скин напрямую, минуя эту проверку.

## Сборка

### Требования
- Java 21 (JDK)
- Internet (для скачивания зависимостей Gradle)

### Компиляция
```bash
cd AlopetsiyaSkins
./gradlew build
```

Готовый .jar файл будет в `build/libs/alopetsiyaskins-1.0.0.jar`

### Установка
1. Положи `alopetsiyaskins-1.0.0.jar` в папку `mods/` клиента
   (инстанс должен быть на NeoForge той же версии, что и сервер)
2. В файле `config/alopetsiyaskins-common.toml` при необходимости укажи:
   - `websiteUrl` — URL сайта (по умолчанию `http://127.0.0.1:3000`)
   - когда сайт переедет на публичный хостинг — поменяй `websiteUrl` здесь,
     и скины будут качаться уже с него
