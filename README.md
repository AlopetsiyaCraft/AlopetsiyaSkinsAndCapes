# AlopetsiyaSkinsAndCapes

Клиентский NeoForge-мод для сервера АлопецияКрафт: рисует игроков в скинах
и плащах, загруженных на сайт, — вместо Стива, которого показывает
offline-режим. Модель персонажа (Стив / Алекс) выбирается на сайте.

## Что делает мод

- Один запросом к `/api/chat/head?nickname=<ник>` получает с сайта всё:
  URL скина, URL плаща и модель (wide = Стив / slim = Алекс)
- Подменяет внешность миксином в `PlayerInfo.getSkin()` — этим одним вызовом
  покрыто всё: модель игрока, портреты в табе (Tab), плащ, рука от первого
  лица
- Модель задаёт явно игрок в настройках сайта (PNG 64x64 сам по себе не
  сообщает, тонкая модель или широкая); без значения на сайте — эвристика
  64x128 = slim
- Плащ любого размера, который принимает сайт (64x32, 22x17, 46x22),
  приводится к ванильным 64x32
- Плащ без скина тоже работает: тело остаётся дефолтным, плащ висит
- Всё кешируется по сессии; неудачные попытки повторяются не чаще раза в минуту
- Скин/плащ/модель меняются прямо в онлайне: внешность перечитывается с сайта
  каждые ~30 секунд, при выходе с сервера кеш очищается (перезаход — уже со
  свежей внешностью). Перезапускать игру не нужно
- Если игрок удалил скин/плащ на сайте — в игре он возвращается к Стиву
- Если у игрока на сайте нет ни скина, ни плаща или сайт недоступен —
  остаётся Стив

Мод чисто клиентский: миксин лежит в секции `"client"` файла
`alopetsiyaskinsandcapes.mixins.json` и на выделенном сервере не применяется.
Серверу мод не нужен — это дополнение только для глаз игрока.

### Почему не серверный мод (SkinRestorer и т.п.)

С версии ~1.20.2 ванильный клиент показывает чужие скины только если
текстуры подписаны ключом Mojang, а подписать может только Mojang
(`PlayerInfo.createSkinLookup`: `flag && !secure() ? default : skin`).
Поэтому серверный подменщик работает лишь для самого игрока (остальные
видят Стива), а клиентский мод подменяет внешность напрямую, минуя эту
проверку.

## Сборка

### Требования
- Java 21 (JDK)
- Internet (для скачивания зависимостей Gradle)

### Компиляция
```bash
cd AlopetsiyaSkinsAndCapes
./gradlew build
```

Готовый .jar файл будет в `build/libs/alopetsiyaskinsandcapes-1.0.0.jar`

### Установка
1. Положи `alopetsiyaskinsandcapes-1.0.0.jar` в папку `mods/` клиента
   (инстанс должен быть на NeoForge той же версии, что и сервер)
2. Старый jar `alopetsiyaskins-1.0.0.jar` удали, если он был
3. В файле `config/alopetsiyaskinsandcapes-common.toml` при необходимости укажи:
   - `websiteUrl` — URL сайта (по умолчанию `http://127.0.0.1:3000`)
   - когда сайт переедет на публичный хостинг — поменяй `websiteUrl` здесь,
     и внешность будет качаться уже с него
